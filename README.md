# Adagio

Site for resesrving the boat "Adagio". Adagio boat is owned by a group of friends who need a way to book and reserve the boat online for their own use. The website should have the following features:

- Create a user
- Login as a user
- See and modify user details
- Create a reservation
- Modify a reservation
- Create an issue notification
- Modify an issue notification
- Upload pictures to reservations
- Upload pictures to issue notifications
- See a calendar view of created reservations and issues
